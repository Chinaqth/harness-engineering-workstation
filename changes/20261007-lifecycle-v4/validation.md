## 已实现行为

- Kernel 负责项目入口识别、确定性 Route、阶段调度、状态及证据记录。
- Domain 通过 lifecycle.json 实现准备、执行、独立评估和总结四阶段 Skill。
- 无匹配 Domain 时直接结束，告知用户未执行具体任务；没有通用或模型兜底。
- 删除旧 Kernel 审批/计划展示门禁；普通执行和环境问题记录后继续可做工作。
- 流程结束、目标达成和验证结果分别保存；没有有效评估时使用 unassessed。
- 原子状态、调用 ID 与结果回执支持跨会话恢复；在途调用先核对已有结果，禁止盲目重放。
- 评估绑定产物摘要；变更后重新评估，旧检查证据不会被当作当前证据。
- 修复和重复评估有界；阶段不可用仍会记录缺口并进入收尾。
- 最终清单包含成果、实际验证、问题、假设/替代和后续事项。
- 专业审计与评估 Skill 迁入 Domain；继承专业执行方法、验收标准和来源记录。
- Bundle 包含可运行调度脚本，支持无 Git 的安装 Runtime 路由、管理 Skill 重定位及事务回退。
